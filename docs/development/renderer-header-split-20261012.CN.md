# Renderer 公共头职责拆分记录

[开发记录索引](README.CN.md) · [正式接口边界](../custom-api.CN.md)

本批只拆公共声明与用途，不改名称、函数签名、结构布局和光栅算法。

- 新增 draw、stats、benchmark 三个窄头；旧 renderer 头继续聚合它们，已有游戏和 facade 不强制迁移。
- 中性 renderer 实现显式包含 draw 与 stats；内部 primitive 头只需要 draw。
- 目录按实际声明归属登记，保留旧聚合头的兼容职责；公共具名入口集合保持，新增头文件不意味着新增绘图 API。
- `raylib_lite_2d_*` 历史名称暂留；五个阶段槽位仍使用 sky/floor/wall/enemy/hud，日志含义与各游戏映射不改。本批不借整理头文件提前做迁移。
- C/C++ 自包含编译、跨语言联接、窄头依赖隔离及聚合头旧入口测试，补充已有像素和资源生命周期验证。

拆分前统计结构 sizeof 为 184，sky_us/triangle_calls/fb_pixels 偏移为 88/108/180；新头在 C/C++ 中维持这些值。该测试针对当前受支持的 Host/ESP 32 位基础类型布局，不宣称任意自定义 packing 或编译器 ABI。

本批不烧录，不沿用旧固件数据宣称新头带来速度提升。双板 v4 验收是此前光栅候选的历史证据。后续命名迁移需要单独列消费者、兼容过渡和回归范围；冻结的 105 个 raylib 名称继续保持。

## 验证结果

相关 focused 检查 23 项、边界检查 44 项分别通过（存在重叠），完整 Host 回归 145 项通过。独立 columns/primitives/stack 像素测试、接口登记与冻结审计、84 份 Markdown 链接、`git diff --check` 和隔离发包检查通过；窄头与聚合头均随组件打包，开发记录排除。目录现为 33 个头文件模块，公共具名入口集合与拆分前严格相等，仍为 417 个。

完整回归曾发现旧架构断言要求核心包含旧 renderer 头；现改为要求 draw/stats，并对所有三份新头及旧聚合头保持中性类型检查。没有削弱对 Raylib/BSP 类型泄漏的限制。

原始日志与源码身份保存在本地 `artifacts/renderer-header-split-20261012/`。本轮没有运行设备路径、发布或删除接口。
