# Neon Rift Rally

[English](README.md) · [示例索引（English）](../README.md)

Neon Rift Rally 是第三人称霓虹摩托竞速游戏。三条赛道各进行三圈比赛，六名对手采用
冲刺、防守和追赶三类策略。玩家可利用尾流、氮气和漂移争夺排名。

![Neon Rift Rally](docs/screenshot.png)

图为 Neon Loop 赛道的 Host RGB565 画面：尾流横幅、速度表、氮气按钮和滚动分数。

## 玩法与操作

### 真机

- 点击左上 `TOUCH >` / `TILT >` / `KEYS >` 循环选择控制方式。初始为 TOUCH，重新开始保留所选方式。
- TOUCH 使用左侧拖动转向；TILT 使用倾斜转向，并允许左侧触摸暂时接管。第二根手指可按住右下角氮气区域。
- TILT 在倒计时期间校准中心；比赛中可保持舒适姿势点击右上 `CENTER` 重新置中。TOUCH 和 KEYS 不接收倾斜转向。
- 倒计时期间点击赛道名称两侧可切换赛道。
- TOUCH / TILT 在真机和 Host 都自动加速；KEYS 仅在按住加速动作时加速。比赛结束后点击结果画面重新开始。
- 速度达到 18 后，大幅转向持续约 0.27 秒会进入漂移；回正兑现短促加速。
  出界、碰撞或离地会取消蓄力。短暂修正方向不会触发漂移。

### Host

- 先将模式切到 KEYS；`A`/`D` 转向，`W` 加速，`S` 刹车。
- `Space`：氮气；`Shift`：漂移。
- `P`：暂停或继续；`Enter`：重新开始。
- TOUCH / TILT 模式下，鼠标左侧拖动和右下角氮气区域沿用真机触摸规则。
- 回放 action `10` / `11` / `12` 分别选择 TOUCH / TILT / KEYS，`13` 重新置中；状态输出包含 `control_mode` 和 `auto_throttle`。键盘回放应先声明 action `12`。

## 竞赛系统

- 摩托采用重左、轻左、正面、轻右、重右五档姿态，反向时逐档经过正面。
- 六名车手（VOLT、NOVA、JADE、BLAZE、ORCHID、FROST）采用有限的起步加速度和
  更紧凑的发车间距。前车占道时会减速，有空间时平滑变道超车；冲刺型直道更快，
  防守型在玩家紧跟且没有明显提速时封堵玩家车道，追赶型向玩家车道靠拢。
- 每场比赛按种子重新生成性格：技术、过弯、侵略性和氮气储备各不相同，名次和
  缠斗每局都有变化。车手过弯走内线，并线前看后视镜，相互借尾流，会在直道、
  刚被超车后或最后一圈开氮气。过弯较弱的车手偶尔在弯中滑出外侧，留出超车空间。
  落后太多的车手会小幅追赶，保持车群在可追范围内。
- 每场有一名宿敌：技术更强、更具侵略性、氮气满额，被玩家甩开时会全力追赶。
  路面上用菱形标记和名字标出宿敌；名次面板下方显示宿敌名次和差距，结算画面
  显示是否战胜宿敌。
- 开氮气的车手尾部有火焰，打滑的车手车身摇摆并溅出火花，每辆车都有尾灯。
  附近车手的加速和打滑以横幅提示（"NOVA BOOSTS"、"VOLT SLIPS GO!"），宿敌
  加速有独立音效。
- 对手车辆和路边精灵按实际相机深度缩放、排序，靠近时持续变大，驶离时自然
  裁出画面；头盔和背部色块帮助辨认不同车手。
- 霓虹海港、落日峡谷和极光雪山使用独立远景与路边物件；弯道标志按方向翻转。
  接地阴影、漂移火花和随速度稍微变宽的视野提供驾驶反馈。
- 海港赛道采用闭合的手工样条走向，前段依次经过港区、仓库弯道和桥面。
  连续护栏、固定间距灯柱、仓库立面与桥架共用道路坐标；坡顶可遮挡后方物体。
  三条赛道的远景缩到画面上方 184 行，路沿收窄，给道路和近景留出空间。
- 峡谷路段以连续岩壁、低护墙和分组石柱围出道路；雪地以雪堤、沿路栅栏和
  路桩组成不同路段。雪地弯道已放缓，避免宽路面在局部回折中相互覆盖。
- 跟在前车后方且横向对齐会积累尾流，充满后获得短促速度奖励。
- HUD 显示：左上角名次和车体耐久，顶部中间圈数、本圈进度和检查点刻度，右上角滚动分数和连击计时，左下角分段速度表，右下角氮气按钮（位于氮气触摸区，外圈点阵表示剩余氮气）。跟车时出现尾流条。
- 超车、被超、尾流、擦身而过、漂移加速、检查点和最后一圈都会弹出简短横幅。高速时地平线方向出现速度线，开氮气时加上彩色拖尾和屏幕边缘光晕。
- 倒计时每个数字有提示音，GO 有独立音效。每类比赛事件都有区分明确的音效和对应的触觉：超车、被超、擦身而过、尾流、氮气、漂移、起跳、落地、检查点、圈完成、完赛、失败、出界和碰撞。
- 每条赛道有独立的合成波音乐循环，内含引擎底噪：Neon Loop 为 A 小调，Sunset Sprint 为 D 大调，Polar Rift 为带钟声琶音的 E 小调。音量随车速和氮气升高，暂停时压低。
- 结算画面显示金银铜徽章、宿敌胜负、比赛用时和分数。

## 实现特点

Host 与真机共用 30 Hz 固定步长模型、程序化弯道和 RGB565 视图。游戏使用固定容量状态、
单张摩托姿态贴图绘制和事件驱动反馈；设备仅保存三条赛道的最好圈速和比赛时间。

`rally_feedback.[ch]` 负责全部音效和触觉，并用桩音频后端测试；`game_module.c` 只转发事件。
`assets_src/generate_audio.py` 用 numpy 合成 16 个音效和三条赛道音乐（共 19 个片段，在混音器默认
20 个片段的预算内）。生成的 WAV 不纳入 git。
