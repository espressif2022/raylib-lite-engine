# Last Zone: Extraction

[English](README.md) · [示例索引（English）](../README.md)

Last Zone 是轻量战术射击游戏。玩家依次完成五个训练任务，搜索补给、清除敌人并抵达
撤离点。任务越靠后，弹药和护甲越少，精英敌人越多。

![Last Zone: Extraction](docs/screenshot.png)

上图为 Dock 任务的 Host RGB565 画面。

## 玩法与操作

### 真机

- 点击简报部署或重新部署。
- 左摇杆移动，推到外环前方可冲刺。
- 右侧拖动控制转向和俯仰。
- 点击射击键开火或打开面对的门；按住射击可稳住枪机。
- 雷达面板可以拖动，避免遮挡战场。

### Host

- `W`/`S`：前进和后退；`Q`/`E`：横移。
- `A`/`D`：转向；`Shift`：冲刺。
- `F` 或 `Ctrl`：射击或交互。
- 鼠标右侧拖动：调整视角。

## 战役

| 任务 | 定位 | 敌人 |
| --- | --- | ---: |
| Dock | 观察教学 | 5 |
| Depot | 区域控制 | 7 |
| Command | 侧翼突破 | 8，含 2 名精英 |
| Ghost | 伏击 | 8 |
| Run | 强攻 | 9，含 3 名精英 |

设备 NVS 保存战役进度和各任务最好成绩。

## 敌人

- 三种角色，以肩部色块区分：步枪手（蓝）在中距离依托掩体，侧翼手（琥珀）移动
  更快并选择玩家视野外的位置，重装兵（红，即精英）需三发命中，持续压上且几乎
  不被打断。
- 巡逻兵沿岗位附近的路线行走，停下环顾。视野为 120 度扇形，可以从身后绕过。
  瞥见玩家时先累积怀疑（头顶琥珀条和"?"），而不是立刻警戒；远处静止不易被
  发现，空旷处冲刺则很快暴露。看到可疑身影后丢失目标的巡逻兵会走过去查看。
  冲刺和枪声仍然全向可闻。
- 进入警戒的敌人在短暂延迟后呼叫约七格内的巡逻兵（头顶出现天线图标，随后弹出
  "ENEMY RADIO"）。先击倒呼叫者可打断通话，额外 +50 分。
- 敌人射击带命中判定：移动降低被命中率，冲刺降低更多，近距离更容易被命中。
  未命中时出现曳光、指向射手的黄色箭头和呼啸音效。
- 命中会让目标踉跄并打断瞄准。受伤的步枪手或侧翼手撤回掩体，重装兵继续推进。
  搜索中的敌人会在最后目击点附近来回搜寻，而不是原地站立。
- 雷达光点显示每个敌人的朝向；平静巡逻为暗色，产生怀疑为琥珀色。

## 实现特点

Host 与真机共用固定步长模型、透视场景和 RGB565 视图。玩法包括掩体、窗洞、门、弹药、
护甲、精英敌人和撤离判定；音效与震动由语义事件驱动。

- 准星随移动、冲刺和后坐力张开，按住开火稳定时收紧；弹匣打空时变红。
- 雷达为半透明面板，带扫描臂和闪烁的敌方光点；有敌人进入警戒时边框闪烁。
- 击杀时弹出 `TARGET DOWN` 横幅并显示击杀数。拾取、开门、空弹匣和开门提示都带底板，在明亮天空前也能看清。
- 侦察时播放紧张的潜行音乐；任一敌人进入警戒或交战时切换为节奏更强的战斗音乐，接触结束后保持约五秒。开门、出击和阵亡有独立音效，暂停时音乐压低。
- `assets_src/generate_audio.py` 合成全部音频片段，生成的 WAV 不纳入 git。调试用的 FPS 标签只在定义 `LAST_ZONE_SHOW_FPS` 时编译。
