# Sky Hop

[English](README.md) · [示例索引（English）](../README.md)

Sky Hop 是四关横版平台跳跃游戏。收集金币、踩掉巡逻怪、借弹簧起跳并抵达关卡终点旗帜；
生命、分数和连续收集奖励会跨关保留，完成第四关即完成整局。

四关各有天气和配色：晴空草地（飞鸟）、风暴山脊（雨和闪电）、霜冻群峰（降雪）、余烬岩岗（飘散火星）。

## 玩法与操作

### 真机

- 点击标题卡开始，先松手再操作；暂停恢复也会消费本次触摸，避免误走动。
- 屏幕底部两个箭头按钮控制左右移动，`JUMP` 按钮控制跳跃；短按小跳，长按跳满。
- 可同时按住移动和跳跃。仅可见按钮矩形响应操作，地面区域和按钮间隙不会误触；右上角暂停，松手后重新触摸继续。触摸与键盘动作独立，释放一种输入不会清除另一种。
- Button、Joystick 和 IMU 输入会先映射为相同的游戏动作。
- 不落地连续踩敌会叠加奖励：250、500、1000，之后每次 2000 分。受伤后角色闪烁并短暂无敌。
- HUD 显示生命、已收集金币、分数、最高分、关卡名和进度条；第一关开头会出现简短提示；首个安全矮台阶需要按住跳跃跨越，走近时会持续提示，不用先冒跌落风险。
- 每类事件都有独立的芯片音乐音效和触觉反馈：跳跃、落地、金币、踩敌、弹簧、检查点、受伤、过关、失败和开局。第 1、3 关播放白天主题，第 2、4 关播放夜晚主题，暂停时音乐压低。

### Host

- `A`/`D` 或方向键：移动。
- `Space`：跳跃。
- `Enter`：开始或进入下一关。
- `P`：暂停或继续。

## Host 预览

在仓库根目录运行：

```sh
python3 tools/game_cli.py sim examples/sky_hop
```

Host 与真机共用玩法模型、Camera2D 世界视图和 RGB565 绘制代码；音频、物理输入和
LCD 上屏仍需在设备上验证。

在 Host 上预览后面的关卡时，把 `SKY_HOP_SIM_LEVEL` 设为 1–4，例如
`SKY_HOP_SIM_LEVEL=3 python3 tools/game_cli.py sim examples/sky_hop`。原生构建不读取这个变量。

## 实现特点

玩法模型（`platform_game.[ch]`）每个 tick 用事件位掩码报告发生了什么。视图（`sky_hop_view.[ch]`）
把事件变成粒子、得分飘字、挤压拉伸和屏幕震动；反馈模块（`sky_hop_feedback.[ch]`）把事件变成音效和触觉。
`game_module.c` 只负责输入和生命周期。所有对象都是固定容量。最高分只在本次运行内保留，不写入存档。

`assets_src/generate_audio.py` 用 numpy 合成全部音效和两段音乐循环，生成的 WAV 不纳入 git。
原生固件把打包后的资源嵌入应用镜像。
