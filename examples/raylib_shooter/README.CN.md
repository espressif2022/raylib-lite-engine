# Mosaico Raylib Shooter

[English](README.md) · [示例索引（English）](../README.md)

Raylib Shooter 是有明确终点的纵向街机射击游戏。武器自动开火，玩家操纵飞船躲避敌弹并击破编队；有效游玩 80 秒后出现终局 ACE，击败它即可胜利。暂停时间不计入这一进度。

## 玩法与操作

### 真机

- 点击标题画面开始。
- 松手后再次触摸只建立新的拖动起点，飞船不会瞬移到手指下；移动手指时飞船跟随相对位移。开局和重试的触摸需要先松手再开始操纵。
- 敌机射击前会出现黄色预警环；重型敌机发射三发散弹，终局 ACE 发射五发散弹。飞船中央白色标记表示小判定核心，受击后有短暂无敌时间。
- 漏掉敌机不会扣生命，也不会直接扣分；损失的是击破得分与连击机会。连续击破可暂时获得 x4 双管、x8 速射。
- 右上角暂停按钮暂停；暂停后重新触摸继续，松手后再拖动。胜利或失败后先松手，再点击结果面板的 `TOUCH TO RETRY` 按钮重试，持续拖动不会误重开。
- 射击、击毁、机体受击、进入新区域、连击强化（x4 双管、x8 速射）、开局和失败都有独立音效和触觉脉冲。对局中播放太空合成器音乐，暂停时压低。

### Host

- 鼠标按下并拖动飞船。
- 方向键或 `A`/`D`/`W`/`S` 可移动。
- `Enter` 开始或重新开始，`P` 暂停或继续。

## Host 预览

在仓库根目录运行：

```sh
python3 tools/game_cli.py sim examples/raylib_shooter
```

## 实现特点

游戏以 30 Hz 固定步长运行，敌人、弹丸和特效均使用固定容量池。绘制代码使用 Raylib
兼容入口并写入 RGB565 帧缓冲，以 480 高逻辑场地适配方形与横屏表面；Host 与真机编译同一套模型和视图源码。

模型没有事件位，因此 `shooter_feedback.[ch]` 逐 tick 比较一组计数快照（射击、击毁、生命、区域、连击、阶段），每 tick 按重要性只播放一个音效，并用桩音频后端测试。`assets_src/generate_audio.py` 用 numpy 合成音频片段，生成的 WAV 不纳入 git。
