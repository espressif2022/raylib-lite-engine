# Tomb Raycast

[简体中文](README.CN.md) · [Examples](../README.md)

> Internal preview: kept in the repository as a raster workload and for internal play; not part of the Registry release package or release CI.

Tomb Raycast is a PS1-style third-person tomb exploration game. Five rooms connect through portals, with ramps, height changes, friezes, burial chambers and pools. All textures are generated by this project.

![Tomb Raycast](docs/screenshot.png)

The image is the Host RGB565 frame of the hall.

## Play and controls

### Device

- Put a finger down on the left half to spawn a floating stick and drag to move.
- Drag on the right half to orbit and pitch the follow camera.
- Tap `JUMP` to jump.

### Host

- `W`/`S`: forward and back; `Q`/`E`: strafe.
- `A`/`D`: orbit the camera.
- `F`: jump.
- Mouse drags on the left and right follow the device stick and camera rules.

## Host preview

From the repository root:

```sh
python3 tools/game_cli.py sim examples/tomb_raycast
```

## Implementation

Host and device share the C model and a perspective-correct textured triangle view. The character is built from low-poly boxes; rooms, portals, sector heights and camera collision are driven by a deterministic model.
