# 灯塔小岛：海盗保卫战 (`pirate_island`)

手绘绘本风三合一益智闯关 + 科技升级游戏，适配 ESP-Mosaico（`480x480`）与 ESP32-S3-BOX-3（`320x240`）：

1. **第一幕 · 划动木闸 + 变道开关**：上下滑动两道红木闸门将海盗弹落水中，放行送信的草帽村民；点击中央「变道」木桥可主动引导海盗与村民换道，克制会跳跃换道的紫巾精锐。
2. **第二幕 · 侦察线索推理抓海盗**：每局随机抽取双重特征线索（`黑帽+持弯刀`、`紫色头巾+抱炸药桶` 或 `偷戴草帽+拿金币`），在窗户、菱形树冠、浆果丛与灯塔后精准揪出符合线索的真凶，避开其他伪装干扰项。
3. **第三幕 · 7×7 圆石围困 + 金石碑连击**：点击圆石种树建房，对抗海盗头目的实时 BFS 最短路突围 AI；根据红圈预判其下一步落点，防范其每 3 回合一次的「连跨 2 步冲刺」，并利用金色石碑触发「买一送一」连锁种树。
4. **海岛工坊（科技可升级）**：每完成一轮三幕防守，从随机刷出的 3 张手绘科技卡中选择 1 项永久升级（`加宽木闸`、`鹰眼探照灯`、`预筑路障`、`加固宝库`），挑战更高轮次与最高分纪录。
