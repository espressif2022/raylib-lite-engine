# Circuit Keep

[English](README.md) · [示例索引（English）](../README.md)

Circuit Keep 是六波制 RGB565 塔防游戏，适配方形和横屏表面。玩家在九个固定基座上建造和改造三类防御塔，阻止敌人沿道路进入右侧核心；第六波结束时核心仍有生命即可胜利。

## 玩法与操作

### 真机

1. 点击开始，进入准备阶段。准备阶段没有倒计时压力，敌人不会自动出现。
2. 在底部选择 `PULSE`、`RAPID` 或 `FROST`。
3. 点击地图上的 `+` 基座预览射程，再点上方 `BUILD` 确认建塔；`CANCEL` 取消。
4. 点击已有塔只选中；选相同类型后点 `UPGRADE` 确认升级，选不同类型后点 `REPLACE` 确认改造。确认区显示实际扣款和已抵扣退款（旧塔投入的 50%，不超过新塔价格）。
5. 准备完成后，取消当前基座选择，点击上方 `START WAVE`；按钮同时显示本波敌人数。约一秒后开始出敌。每波结束后重新进入准备阶段，可继续建造和升级，再手动开启下一波。
6. 右上角按钮暂停或继续；胜利或失败后点击结果面板重新开始。

三类塔分别侧重均衡伤害、高射速和减速控制。FROST 先减速目标，PULSE 命中减速目标时伤害翻倍，RAPID 则额外造成 2 点伤害；组合不依赖塔相邻。
开局、建塔、射击、击毁、新波次、漏怪和失败有音效，并播放背景音乐；暂停时降低音量，胜利或失败后停止。

### Host

鼠标点击和真机触摸使用同一套界面与放置规则。`Enter` 从标题或结算画面开始新一局，`P` 暂停或继续；每波仍需点击 `START WAVE`。浏览器工具栏可暂停、单步和重新开始。

## Host 预览

在仓库根目录运行：

```sh
python3 tools/game_cli.py sim examples/tower_defense
```

## 实现特点

地图来自 Tiled，角色和防御塔使用 RGB565+A8 Atlas。游戏模型采用固定对象池，运行时
不分配敌人、弹丸或特效对象。设备和 Host 共用资源、模型和 C 绘制代码。
